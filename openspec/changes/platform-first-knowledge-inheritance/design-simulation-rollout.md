# 附录 R — 发布前模拟 / 灰度 / 批量复用

> 目标：任何平台发布或租户覆盖，先"看清影响"再生效；高风险可灰度放量；规模化配置可批量、可复用。

## R1 发布前模拟（what-if / dry-run）
平台发布或机构提交覆盖前，系统 SHALL 产出**影响预演**（不落库、纯计算）：
- **结构影响**：将影响哪些组织节点 × 哪些专病/场景维度；与现状的 diff（新增/变更/停用项）。
- **历史回放影响**：对近 N 天历史病例重放，统计"决策结果会变化"的病例数与方向（触发增减、剂量变化），定位高风险变更。
- **安全校验**：是否触发 LOCKED 拦截、是否破坏依赖完整性（附录 D）。
- **覆盖冲突**：与既有下级覆盖的交互（谁最终生效）。
确认通过后方可进入发布/评审（呼应附录 M7、L5）。

## R2 灰度与分批放量（RolloutStrategy）
承接附录 O 轴4 与升级通道 §8.5：
- **ORG_LIST / ORG_SUBTREE**：先发试点机构/子树，验证后扩面。
- **CANARY_BED_PERCENT**：按床位比例灰度放量（原 BED_PERCENT 正确归位为策略）。
- **STAGED**：分批（如 5%→25%→100%）+ 每批观察窗 + 异常自动暂停。
- 全程可一键回退到上一钉点（`VersionActivationTransaction` + `VersionRollbackCommand`），平稳可逆。

## R3 监测与自动护栏
- 灰度期监测关键指标（命中率、拦截率、人工否决率、异常告警）；越阈值自动暂停放量并通知。
- 与可观测看板（附录 N7）联动。

## R4 批量与复用（可批量 / 可复用）
- **覆盖模板**：一组覆盖存为"定制方案"（如"儿科剂量包""本院抗菌谱"），可应用到多机构/多专病维度。
- **批量应用/撤销**：多选组织节点 × 维度，一次应用/回退模板，附预演。
- **跨机构克隆 + diff**：复制 A 机构覆盖集到 B，带三方 diff 与冲突提示。
- **集团统一下发**：集团层 INHERITABLE 覆盖一次配置，下级默认复用（呼应 §4.2）。

## R5 落地对接
- 模拟引擎复用 `VersionReplayService`（历史回放）+ `InheritanceResolver`（影子解析），纯只读、零副作用。
- 灰度策略并入发布命令 `VersionReleaseCommand`；批量/模板为 pkg/versioning 之上的编排层。
