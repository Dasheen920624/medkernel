# 附录 M — 授权体验设计（易用）

> 目标：把"平台优先 + 继承覆盖"的复杂性藏在简单心智后面。配置者无需理解底座，5 分钟能看懂"哪些是平台的、我改了什么、改动影响谁"。

## M1 核心心智模型（一句话教会用户）
> **"全院默认用平台的；你只为需要改的那几条建'例外'；例外可以只管自己，也可以让下级跟着用。"**

界面始终呈现三种状态徽标，颜色固定、全局一致：
- 🟦 **平台**（继承自平台权威，只读）
- 🟩 **本级定制**（本机构 REPLACE/ADD）
- 🟨 **继承上级定制**（来自集团/分院，标注来源层级）
- ⬜ **已停用**（DISABLE，灰显划线）

## M2 三视角切换
顶部一个切换器（平台 / 租户 / 当前机构），同一份列表随视角变化：
- **平台视角**（平台管理员）：维护权威基线、发布、设 `override_policy`（FREE/REVIEW/LOCKED）。
- **租户/集团视角**：在平台之上做集团统一定制（多为 INHERITABLE）。
- **机构视角**（分院/卫生院/科室）：看到"平台 + 上级 + 本级"合成后的有效列表，就地建例外。

## M3 就地建"例外"（覆盖编辑器）
任意资产行右侧统一三个动作，文案不用术语：
- **「改成我们的」**（REPLACE）→ 复制平台版本为草稿 → 改 → 选传播：**「只我们用」(EXCLUSIVE) / 「下级也用」(INHERITABLE)**。
- **「本院不用」**（DISABLE）→ 二次确认；若资产 LOCKED 则禁用此项并提示原因。
- **「新增本院专有」**（ADD）→ 从模板或空白起。
覆盖编辑器顶部恒显 **与平台并排 diff**（左平台/右本级，差异高亮），所改即所见。

## M4 有效视图与来源可解释
- 每行可展开「**来源链**」：平台 v3 → 集团 REPLACE v3.1（复用）→ 本院未改 ⇒ 当前生效 v3.1。
- 一键「**回到平台**」：删除本级覆盖，恢复继承。
- 「**与平台对比**」全局入口：列出本机构所有 REPLACE/DISABLE/ADD 清单（§11 继承差异）。

## M5 批量与复用（可批量/可复用）
- **批量例外**：多选资产 → 一次 DISABLE / 套用同一覆盖模板。
- **覆盖模板**：把一组覆盖存为"定制方案"，可应用到多个分院/科室（如"儿科剂量定制包"）。
- **跨机构克隆**：把 A 分院的覆盖集复制到 B 分院（带 diff 预览）。

## M6 开通向导（引用制，不建副本）
1. 选组织结构（集团→分院→卫生院→科室，可导入）。
2. 勾选要启用的平台知识包（默认全启用、AUTO 升级）。
3. （可选）选起步定制模板。
4. 完成 ⇒ 仅落"引用 + 可选覆盖"，**零副本**，开通秒级完成。

## M7 发布前预演（与附录"模拟/灰度"联动）
平台发布或机构提交覆盖前，弹「**影响预演**」：将影响多少机构/科室、命中多少历史病例、与现状 diff、是否触发 LOCKED 拦截。确认后才生效。

## M8 安全与防错
- LOCKED 资产的"停用/放宽"动作直接禁用并解释（不是报错后才知道）。
- 高风险覆盖提交即进评审队列，状态可视（草稿/待评审/已发布）。
- 危险操作（停用安全红线、批量 DISABLE）二次确认 + 影响预演前置。

## M9 简洁美观（落地约束，承接既有前端规范）
- 复用现有 Antd + CSS Module；禁内联样式、禁 px（用 rem）、禁嵌套三元；色彩仅四态徽标，克制。
- 列表默认按"平台分组 → 本级定制"两段，搜索/筛选（按状态/科室/风险）齐全。
- 移动端/嵌入端只读有效视图（embed 域）。
