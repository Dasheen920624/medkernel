# 第三方接入验收清单（INTEG-02）

| 阶段 | 检查项 | 证据 |
| --- | --- | --- |
| 准备 | 确认租户、组织作用域、责任人、适配器协议和事件范围 | 对接登记记录、审批记录 |
| OpenAPI | 按 `/v3/api-docs/medkernel-third-party-integration` 生成客户端或联调脚本 | 生成命令、版本号、联调脚本 |
| 字段映射 | 使用 `field-mapping-template.json` 完成外部字段到 API-01 标准上下文映射 | 映射文件、样例 payload、质量校验结果 |
| 术语 | 临床编码经 TERM-01 映射或进入人工待裁 | 映射包版本、冲突/待裁记录 |
| 鉴权 | 权限缺失、租户缺失、签名错误均被拒绝 | 403 / 401 / 校验失败响应与 traceId |
| 幂等 | 重放同一 `messageId` 和 `Idempotency-Key` | 首次结果复用或幂等冲突证据 |
| 降级 | 外部系统断连或回调不可达 | `NOT_CONNECTED` / `NOT_SYNCED` 响应、日志、审计 |
| 审计 | 执行类操作可追溯 | 审计事件、traceId、目标对象、错误码 |
| 医疗边界 | 无接口绕过引擎直写医嘱、病历、上报、支付或设备控制 | 代码审查记录、接口清单 |
