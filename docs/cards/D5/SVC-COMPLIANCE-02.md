## 目标
把**审计 + 证据包 + 依赖运行状态 + 备份恢复就绪 + 离线运行就绪**编排为统一服务包：审计可查可导（带证据），外部依赖无连接时诚实显示 `NOT_CONNECTED`/`MODEL_DISABLED`；数据库备份和恢复由部署侧脚本及隔离演练执行，应用只读呈现配置与演练证据；离线运行依赖本地包和本地执行器，不设置尚未定义的商业许可闸门。

## 现状（搬迁时核查 2026-05-30，以 `medkernel-backend` 为准）
已具备：`AuditController` 提供租户隔离审计查询，`ExportApprovalController` 与 [EVID-01](EVID-01.md) 提供审批、真实文件、签名和验签；`RuntimeOperationsController` 提供依赖健康、备份就绪和国产化状态；部署目录提供真实备份、恢复与隔离演练脚本；[SYS-05](../D0/SYS-05.md) 已验证本地执行器离线运行。当前收口重点是统一契约、普通/专家视图边界和端到端验收。

## 功能要求（原子可测条目）
- [ ] FR-1 审计查询：按条件查审计事件（`AuditEvent`，[API-13](../D0/API-13.md) 分页），真实。
- [ ] FR-2 审计导出：导出审计 + 证据（[EVID-01](EVID-01.md) 签名），导出审批（[SYS-06](SYS-06.md)）。
- [ ] FR-3 运行状态：数据库、图投影、模型工作流等依赖状态真实，无连接标 `NOT_CONNECTED`/`MODEL_DISABLED`，不伪造绿灯。
- [ ] FR-4 备份恢复保障：应用只读返回 RPO、RTO、校验策略和最近隔离恢复演练证据；备份/恢复执行只在部署侧进行，应用不提供执行端点。
- [ ] FR-5 离线运行就绪：验证本地包、本地执行器和院内权威数据可在断外网时运行，不依赖外部许可服务。

## 接口契约 / 页面契约
### 接口契约（引擎/API 卡）
- 端点：`GET /api/v1/compliance/audit/events` · `POST /api/v1/compliance/audit/snapshot` · `GET/POST /api/v1/compliance/exports*` · `GET/POST /api/v1/compliance/evidence/snapshots*` · `GET /api/v1/system/operations`
- DTO：审计事件、导出审批、证据快照、运行状态均使用 Record DTO；信封 `ApiResult`/`ProblemDetail`。
- 状态机：导出审批和证据生成按真实任务状态推进；依赖健康使用告警状态。应用内无备份执行状态机、无许可状态机。
- 幂等 / traceId：导出和证据生成幂等；trace（[OBS-01](../D0/OBS-01.md)）。

## 数据与迁移
- 复用 `audit_event`、导出审批和证据表；运行状态由真实配置和依赖探测实时汇总。部署侧备份文件与恢复演练证据不伪装成应用业务表；不新增许可表。
