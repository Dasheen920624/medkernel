## 目标
提供规则引擎 **B0 真实**：**三层配置**（L1 模板 / L2 可视化条件树 / L3 DSL）+ **八阶段治理** + **仿真**（病例选择器跑真实快照）+ **测试病例**（阳/阴/边界/冲突）。让医务处/质控/专家**无需写死 yml**即可配置规则集，经同行评审、委员会会签、影子、灰度、全量和监测后供 D3 临床消费。

## 功能要求（原子可测条目）
- [x] **FR-1 三层配置**：L1 从模板实例化；L2 可视化条件树（与/或/比较/分组）双向 ↔ L3 DSL；三层产出**同一 `RuleDefinition`**，互转无损。
- [x] **FR-2 DSL 执行**：`RuleDslEvaluator` 对标准上下文（[API-01](API-01.md)）求值，输出 `RuleActionResult` + **可解释**（命中条件/取值/来源）。
- [x] **FR-3 测试病例**：每规则可挂阳性/阴性/边界/冲突用例（`RuleTestCase`）；发布前必须**全绿**。
- [x] **FR-4 仿真**：病例选择器选真实/脱敏患者快照 → 跑规则 → 展示命中与解释（不写库、不发提醒）。
- [x] **FR-5 治理发布**：测试与影响分析 → 同行评审 → 委员会会签 → 影子 → 灰度 → 全量 → 监测 → 退役，发布执行复用 [SYS-04](SYS-04.md)。
- [x] **FR-6 发布门禁**：高危规则（`RuleRiskLevel=HIGH`）无测试病例/无影响分析/无审核 → **拒绝发布**（详规 §4.7 / 核心 §13）。
- [x] **FR-7 分级动作卡**：支持多动作、来源、建议项和覆盖理由；运行结果输出 CDS Hooks 卡片，高危动作强制医师确认。
- [x] **FR-8 交互治理**：支持执行优先级、规则抑制、同患者窗口去重、发布前静态冲突检测和人工继续理由留痕；被抑制/去重结果不重复返回动作。
- [x] **FR-9 适用域**：统一配置人群纳入/排除、组织范围、`INPATIENT/OUTPATIENT/ED/FOLLOWUP` 场景、生效期和稳定灰度；运行期先判定适用性再求值，不适用时不触发动作且继续后续规则。
- [x] **FR-10 八阶段治理**：`DRAFT → PEER_REVIEW → COMMITTEE → SHADOW → CANARY → FULL → MONITOR → RETIRED`；高危多签、作者禁自审、职责分离、影子先行、全量授权和退役封存均为后端硬门禁。
- [x] **FR-11 影子运行统计**：`SHADOW` 阶段真实流量只记录不动作，统计命中/未命中/误报；误报必须来自人工复核且留审计。
- [x] **FR-12 能力开关灰度**：递归条件树与临床算子按系统默认 / 租户覆盖灰度；开关关闭时诚实拒绝高级语义，不退化为错误计算。
- [x] **FR-13 事件触发硬超时**：临床事件触发求值走配置中心时延预算；超时 / 下游不可用返回不可用并转人工核查，高危 `UNKNOWN_AS_BLOCK` 不静默放过。
- [x] **FR-14 职责分离与审计防篡改**：作者、当前会签人和发布人不得重叠；越权理由绑定当前租户真实执行事实；审计哈希链覆盖摘要与租户口径。
- [x] **FR-15 边界失败语义**：值集展开超上限、单位不可换算、受控公式入参非法、参考范围缺失和时间戳缺失均以 `UNKNOWN` 条件证据表达，证据包含错误码 / 错误消息。

## 接口契约 / 页面契约
### 接口契约（引擎/API 卡）
- 端点：执行/仿真/测试能力，REST 客户面在 [API-05](API-05.md)；治理使用 `/rules/{ruleId}/governance/signoffs` 与 `/rules/{ruleId}/governance/transitions`；人工继续使用 `POST /api/v1/engine/rule/rules/executions/{executionId}/override`；影子统计使用 `GET /rules/{ruleId}/shadow-stats`，影子反馈使用 `POST /rules/executions/{executionId}/shadow-feedback`。
- DTO：复用 `RuleDefinition`/`RuleVersion`/`RuleTestCase`/`RuleSimulateRequest`/`RuleActionResult`/`RuleGovernanceResponse`。
- 状态机：规则治理八阶段闭集复用 [SYS-04](SYS-04.md) 发布端口，规则域只编排临床会签与门禁。
- 幂等 / 错误码 / traceId：高危无测试病例发布 → `ENG-RULE-004`；DSL 语法错 → `ENG-RULE-001` + 行列；全链路 traceId（[OBS-01](../D0/OBS-01.md)）。
### 页面契约（页面卡 —— 规则库页，S5）
- 路由元数据：sectionKey `pilot` / menuKey `rule-library` / requiredPermissions 规则配置 / requiredRoles 医务处·质控·专家。
- 结构：PageShell（[BASE-08](../D0/BASE-08.md)）+ 规则列表（大列表 [API-13](../D0/API-13.md)）+ 三层编辑器（L1 模板 / L2 条件树画布 / L3 DSL）+ 仿真面板 + 八阶段治理步骤 + 六态。
- 主按钮 ≤1（新建/发布上下文相关）/ 默认筛选 ≤3（域/状态/风险）/ 默认角色视图。
- 五维 RBAC 点位：菜单 / 动作（发布权仅医务处）/ 数据（按 org）/ 资产（规则集）/ 环境。
- 样式：仅引用 [BASE-10](../D0/BASE-10.md) token + [体验契约](../../EXPERIENCE_CONTRACT.md)；禁硬编码 hex/px。
