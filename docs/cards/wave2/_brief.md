## 第二阶段设计校正（2026-06-13 · 用户决策 + Opus；**优先级高于下方写于 2026-05-31 的早期口径**）

> 本节是 wave2 经 P1–P5 多轮迭代后的**现行权威设计**。早期口径只假设 Dify/Ollama 模型推理，**未含 Agent 工具协助生产、双形态生产、生产中心定位、引擎数据服务层/CLI/MCP 接入底座**——这些是本节校正的核心。冲突时本节赢（核心 > 本节 > 下方早期段 > 卡）。生产侧 IA 见核心 §2.0 双产品面。

### 1. 双产品面与生产中心（定位）

- **生产中心（逻辑角色 · 外网 / SaaS 形态）**：**当前实例 = 134，临时、可迁移、可配置，不硬绑主机**（主机地址走配置中心，日后可换服务器）。只吃**公开医学资料**（指南/说明书/标准术语/共识文献），**不接触任何患者数据**，故在此调境外大模型 API / Agent 合规（无个人数据出境，核心 §1/§8）。产物归**平台主源 `t-1`**。
- **菜单 IA 走核心 §2.0 双产品面**（原则驱动、不硬锁数量）：知识生产侧另立「知识生产」一级域（AI 工厂/编排/审核台/数据服务/CLI·MCP），临床客户角色不可见；临床运行侧以当前五大主域为基线、可经产品裁决扩展。
- **运行侧（医院内网，碰患者数据）**：只用本地模型 / 纯 B0；知识包只读订阅；医师确认才进病历（核心 §6/§10）。

### 2. 双形态生产 + 四生产器（两条物理隔离管道，单一候选池统一治理）

- **外网·平台主源管道**：134 用 API 大模型 / Agent 生产**平台主源知识**（公开资料），进 `t-1` 发布账本，客户租户只读订阅（核心 §7「平台源不可污染」/ §9「平台主租户唯一」）。
- **内网·院内覆盖管道**：客户租户有**院内独有知识**（本院制度/经验/本地化），手录不现实，用**本地大模型（Ollama/国产化，不出网）**解析生成候选；**只生成属于本租户的覆盖/新增资产，严格隔离，禁与平台主资产混合、禁反写平台主源**（核心 §9）。

| 生产器 | 形态 | 网关路由 | 归属管道 |
|---|---|---|---|
| ① API 大模型自主 | 外网 | B2 外部（Claude / OpenAI 兼容 API） | 平台主源 |
| ② Agent 工具协助（Claude Code / Codex，跑在生产中心，当前 134） | 外网 | 经 MCP/CLI 回写 | 平台主源 |
| ③ 本地大模型生成 | 内网 | B1 本地（Ollama / 国产化） | 院内覆盖 |
| ④ 人工录入 / 批量导入 | 内外网 | 无模型 | 按租户 |

全部经**统一生产编排层** → 单一候选池 → 同一安全流水线 → 审核台 → 权威替换 → 知识包。红线：**AI 只产候选不产事实**。

### 3. 引擎数据服务层 + 产品级 CLI + MCP 服务（接入底座 · 回收 2026-05-26 原始需求）

> 原始需求出处：`docs/superpowers/specs/2026-05-26-engine-data-service-mcp-cli-clinical-design.md`（有完整规范但从未落卡，本节回收，新建卡 `DATASVC-01`）。

- **引擎数据服务层**：把规则/知识/路径/推荐/质控/随访/模型/审计的运行事实沉淀为统一读模型；四入口（临床端嵌入 / 管理质控端 / 产品级 CLI / MCP 服务）**共用同一后端合同**。
- **产品级 CLI**（`knowledge`/`rules`/`clinical-signals`/`privacy`/`exports`/`diagnostics` 命令域）：交付/运维/Agent 脚本抓手；走后端鉴权，不读本地库连接串。
- **MCP 服务**（`searchKnowledge`/`checkKnowledgeExistence`/`explainRule`/`queryRuleUsage`/`summarizeEngineSignals`/`validatePrivacyPolicy`/`getClinicalContextExplanation` 工具）：授权 AI Agent 与模型网关的受控工具层，**也是 Agent 协助生产（生产器②）的技术底座**。
- **铁规**：CLI/MCP **不绕治理** —— 只调受控工具、不直连库、不读原始病历、不绕身份/权限/脱敏/审计/降级；数据分级 D0–D5，**D5 重要个人信息禁入模型/CLI/MCP**；D3/D4 落库字段级加密；脱敏后端化。

### 4. 模型网关全链赋能（升为第二阶段必做，呼应 LLM-05）

模型能力网关不止服务知识工厂，须接进**每个引擎链**：术语映射、规则、路径、CDSS 推荐、报告解读、病历质控、随访。生产侧路由 B2（外网公开资料），运行侧路由 B1（本地）/B0。数据最小化（[LLM-03](LLM-03.md)/[OPT-09](OPT-09.md)）按形态强制；关模型全链 B0 可跑（铁律 #4）。

### 10. 首发核心知识包完整性目标（知识全景 · 全医疗专业领域全量，2026-06-13 用户要求「达到完美」）
