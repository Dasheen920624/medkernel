## 目标
生产全量、可对账、可废止迁移的编码系统、值集、标准单位和系统状态字典基础包，消除各引擎重复枚举和单位歧义。

## 功能要求（原子可测条目）
- [ ] FR-1：编码系统登记 namespace/URI、官方版本、层级、有效期、许可和完整发行清单；选定版本全量导入。
- [ ] FR-2：值集绑定编码系统版本、成员有效期、包含/排除规则和用途；成员引用零孤儿。
- [ ] FR-3：单位登记标准符号、中文名、量纲、别名、换算、精度和禁用歧义表达；跨量纲换算拒绝。
- [ ] FR-4：系统字典覆盖人员、机构、就诊、诊断、医嘱、报告、标本、过敏、风险、状态、动作和触发点等稳定受控值域。
- [ ] FR-5：废止码保留历史并声明 replacement/effectiveTo；模型不得生成编码、值集成员或单位换算。

## 接口契约 / 页面契约
- 复用 `TERMINOLOGY`、`VALUE_SET`、版本、引用、包发布和字典映射接口。
- 导入结果返回清单对账、层级、重复、值集成员、量纲和废止替代报告。
- 非法编码、许可缺失、清单不一致、循环层级、孤儿成员或量纲冲突失败关闭。

## 数据与迁移
- 复用术语/值集/统一版本表；单位和系统字典若现有承载不足，实施时补单一归属表与五方言迁移，禁止在各引擎复制枚举表。
- code system + version + code 唯一；所有发布资产带 tenant/org/version/status/audit。

## 视角清单
1. 产品架构：单一编码/值集/单位/系统字典底座服务所有领域。
2. 产品体验：中文标签优先，专家模式展示标准码与版本。
3. 系统与数据架构：支持百万级术语、服务端分页、批导、索引和幂等。
4. 临床医疗安全：钾钠、左右、剂量量级、单位换算等高危近似强制 HIGH。
5. 知识与数据治理：官方版本全量对账，映射与基础码分离。
6. 安全合规与监管：许可受限编码不得越权分发。
7. 集团化与多租户治理：平台标准只读，院内字典映射按 org 发布。
8. 集成与互操作：标准码、值集和单位版本随接口合同传递。
9. 运维 / SRE / 国产化交付：支持离线全量包、增量差异、回滚和国产库。
10. 质量与真实性审计：条目数、hash、层级、成员、量纲和替代关系可复算。
11. AI / 模型治理与可降级：导入/校验/查询全 B0；模型仅辅助候选映射。
