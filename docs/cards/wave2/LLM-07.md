## 功能要求（原子可测条目）
- [ ] FR-1 基准集：覆盖字典/规则/路径/推荐/解释的医学回归用例集（带期望）。（**机制 + `rule.draft` 首发真实红线基线 + 后端维护入口已建**：`RegressionBaselineSeeder` 从 OPT-04 ACTIVE 已审红线投影启用用例，`ModelEvalController` 支持带 `source_reference` 的新增/启停/版本/批量导入；**无真实基准集时诚实记 `FAILED` 不自动认证**。剩余字典/路径/推荐/解释能力仍需导入真实题并在 OPT-06 评测台前端承载，故不标全覆盖）
- [x] FR-2 引用真实性：产出引用必须可回溯到真实来源；造假引用判 FAIL。（逐用例精确匹配已登记 `source_reference`；任意非空字符串不能冒充引用。本地 provider 正文真实输出精确引用时提取为引用证据，未输出或输出其他来源均 FAIL）
- [x] FR-3 红线：越 [OPT-04](../D3/OPT-04.md) 红线（禁忌/剂量上限/危急）的产出拦截。（越红线判 FAIL）
- [x] FR-4 专家复核：高风险能力换版需医学专家复核签字才放行。（`sign-off` 仅质量与医保治理员可执行，服务层强制签字人与评测执行人分离并校验已绑定 MFA；签字以 `PENDING_REVIEW` 条件更新一次性原子跃迁，并发请求不能覆盖首位审核人）
- [x] FR-5 门禁：回归不过 → 阻断该 provider/版本上线（接 [LLM-08](LLM-08.md)/[LLM-04](LLM-04.md)）。（评测运行绑定请求能力码、provider 实际配置/返回模型版本和完整启用基准集 SHA-256 指纹；知识生产 readiness 只接受当前能力且基准集完全未变的 `PASSED`，其他能力或同题数旧结果不能串线放行）
