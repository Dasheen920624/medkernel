# 隔离沙盘演练平台设计

> 日期：2026-06-19  
> 状态：已确认设计，待实施  
> 范围：`pilot-hospital` 沙盘中的 10 条规则场景与 5 个外圈引擎场景

## 1. 目标

建设一套最干净、最纯粹、可完整演练的机构级沙盘平台：

1. 10 条沙盘规则全部具备可执行 DSL、公开权威来源、四类测试样本、治理记录和运行证据。
2. 路径、推荐、随访、质控评估、嵌入三模式 5 个外圈场景全部调用真实业务服务闭环。
3. 所有资产、上下文、运行记录和审计事实仅归属 `pilot-hospital`。
4. 沙盘永远不继承、不引用、不回退到 `t-1` 平台规则或平台知识源。
5. 沙盘不依赖配置包；删除既有固定版本号及“先建配置包才能演练”的口径。
6. 所有页面、API 和证据明确标注“仅供演练，禁止生产诊疗”。

## 2. 不变量

### 2.1 隔离不变量

- 沙盘规则的 `tenant_id` 必须等于当前演练机构租户。
- 沙盘运行不得查询平台租户规则作为继承或兜底。
- 沙盘规则不得进入生产临床事件消费、正式发布、平台分发或租户继承链。
- 沙盘上下文只能由沙盘编排入口创建，来源固定为 `MEDKERNEL_SANDBOX`。
- 沙盘资产不得绑定平台知识包、平台配置包、平台版本包或平台授权。
- 删除沙盘代码、脚本、测试、页面和当前接力文档中的旧固定版本号及其配置包前置说明。

### 2.2 医疗安全不变量

- 所有规则均为“公开依据驱动的演练规则”，不宣称经过本院临床委员会正式批准。
- 规则只生成提示、核查任务或人工确认建议，不自动开立或修改医嘱。
- 不自动诊断、不自动拒付、不为了 DRG/DIP 修改真实诊断或病历。
- 高风险动作必须显示来源、命中事实、人工确认要求和演练标识。
- 演练治理签署只证明流程可运行，不冒充真实临床专家生产签署。

## 3. 推荐架构

采用一等公民的 `SANDBOX` 运行环境，不使用伪配置包或特殊版本号绕过正式门禁。

### 3.1 沙盘规则集

新增机构级沙盘规则集：

- `ruleset_id`
- `tenant_id`
- `ruleset_code`
- `revision`
- `status`
- `usage_scope=SANDBOX_ONLY`
- `disclaimer`
- `created_by/created_at/updated_by/updated_at/trace_id`

规则定义增加明确的部署环境与规则集归属：

- `runtime_environment=PRODUCTION|SANDBOX`
- `sandbox_ruleset_id`（仅 `SANDBOX` 必填）
- 正式规则继续使用正式发布约束；沙盘规则不使用配置包版本。

约束保证：

- `PRODUCTION` 规则不得绑定沙盘规则集。
- `SANDBOX` 规则必须绑定同租户的 ACTIVE 沙盘规则集。
- 沙盘规则不得被正式临床事件适配器选中。

### 3.2 沙盘上下文

正式上下文仍保持配置包版本校验，不放宽生产合同。

新增独立沙盘上下文合同：

- `context_source=SANDBOX`
- `sandbox_ruleset_id`
- `sandbox_ruleset_revision`
- `synthetic_data_flag=true`
- `production_eligible=false`

沙盘编排调用 `ContextSnapshotService.createSandbox(...)`。该入口复用标准上下文校验、资源持久化、映射、幂等和审计，但校验当前租户 ACTIVE 沙盘规则集，不校验配置包。

关系库应使用显式来源字段和互斥约束表达正式上下文与沙盘上下文，不允许把规则集版本塞入 `package_version` 冒充配置包版本。

### 3.3 运行选择

规则运行候选按上下文来源闭集选择：

- 正式上下文：仅选择正式环境规则，并保持既有正式包版本一致性。
- 沙盘上下文：仅选择当前租户、当前规则集、`SANDBOX` 环境规则。
- 沙盘上下文禁止平台规则继承与平台兜底。
- 正式上下文禁止选择沙盘规则。

推荐引擎、规则试运行和沙盘编排均复用同一候选选择器，避免三套判断漂移。

### 3.4 外圈演练资产

为 `pilot-hospital` 创建独立沙盘资产套件：

- 急诊处置路径模板；
- 随访闭环模板；
- 质控评估指标；
- 推荐综合场景所需本地资产；
- 嵌入三模式启动合同。

这些资产使用 `runtime_environment=SANDBOX` 与 `sandbox_ruleset_id` 归属，不依赖平台资产或配置包。对应正式运行查询必须排除沙盘资产。

## 4. 十条规则

每条规则必须具备：

- 权威来源名称、URL、发布日期或版本、检索日期；
- 演练适用范围与明确免责声明；
- 结构化 DSL；
- 阳性、阴性、边界、冲突四类确定性合成样本；
- 测试执行结果；
- 同行评审、委员会、影子、灰度、全量、监测流程证据；
- 沙盘运行命中与未命中证据；
- 不自动执行临床动作。

| 规则 | 演练行为 | 主要权威依据 |
|---|---|---|
| 血钾危急值 | 对结构化严重高钾结果生成强提醒和人工复核任务 | UK Kidney Association 高钾管理指南；机构危急值制度在真实部署时必须重新配置 |
| 华法林与阿司匹林联用 | 对抗凝药与抗血小板药并用生成出血风险复核提醒 | ACC 抗凝与抗血小板联合治疗共识 |
| 肾功能不全造影剂风险 | 对严重肾功能受损且拟用造影剂生成风险评估提醒 | ACR Contrast Manual |
| 胸痛与肌钙蛋白异常 | 对胸痛场景与结构化肌钙蛋白异常生成 ACS 紧急评估提醒 | ESC 急性冠脉综合征指南 |
| 影像危急结果回报 | 对结构化危急影像标记生成及时沟通与闭环记录任务 | ACR 诊断影像发现沟通规范 |
| 出院带药与随访核查 | 对出院药物核对或随访要素缺失生成核查任务 | WHO 用药安全材料；国家卫健委病历与医疗质量制度 |
| 随访 INR 异常 | 对华法林随访中的结构化 INR 异常生成复核与联络提醒 | NHS Specialist Pharmacy Service 华法林监测建议 |
| DRG/DIP 合理性提示 | 对分组所需诊疗事实或编码证据缺失生成合规核查提示 | 国家医保局 DRG/DIP 改革与经办规范 |
| 病历内涵质控 | 对结构化诊疗记录中的时效、依据或一致性问题生成整改任务 | 国家卫健委病历书写基本规范与医疗质量安全核心制度 |
| 病历结构化完整性 | 对必填结构化要素缺失生成完整性提示 | 国家卫健委病历书写基本规范 |

具体阈值必须来自所引用来源或明确标记为“演练参数”，不得把演练参数宣称为全国统一医学常量。

## 5. 五个外圈场景

### 5.1 路径

以机构本地沙盘路径模板完成：

`沙盘上下文 → 入径 → 节点推进 → 状态回查 → 审计证据`

### 5.2 推荐综合卡

以本地规则命中和标准上下文生成推荐卡，验证来源、风险级别、人工确认、去重、可见卡和抑制卡统计。

### 5.3 随访闭环

以机构本地沙盘随访模板完成：

`生成计划 → 创建任务 → 异常结果 → 回院建议 → 闭环状态`

### 5.4 质控评估

以机构本地沙盘指标完成：

`快照评估 → 发现问题 → 创建整改 → 复核 → 关闭`

### 5.5 嵌入三模式

验证 IFRAME、SDK、API 三种模式的启动令牌、权限、过期、来源域和审计，不暴露真实患者信息。

## 6. 数据与 API

新增或扩展 API：

- 查询当前机构沙盘规则集；
- 创建、激活和停用沙盘规则集；
- 创建沙盘上下文；
- 查询沙盘资产准备度；
- 执行全部场景或单场景；
- 查询运行证据与失败步骤。

所有写接口须验证：

- 当前租户与请求租户一致；
- 资产归属当前租户；
- 环境为 `SANDBOX`；
- 沙盘规则集状态有效；
- 请求不能引用平台资产；
- 操作者持相应规则、路径、随访、评估或沙盘权限。

## 7. 错误处理

- 缺本地资产：返回具体缺项，不回退平台资产。
- 规则集未激活：结构化返回 `SANDBOX_RULESET_NOT_ACTIVE`。
- 发现平台引用：返回 `SANDBOX_PLATFORM_REFERENCE_FORBIDDEN`。
- 正式入口尝试运行沙盘资产：返回 `SANDBOX_ASSET_PRODUCTION_FORBIDDEN`。
- 场景执行失败：保留已完成步骤与真实错误，不返回伪成功。

## 8. 测试策略

按 TDD 实施：

1. 迁移合同：五方言字段、互斥约束、中文注释和索引一致。
2. 隔离合同：沙盘不读取平台规则，正式运行不读取沙盘规则。
3. 上下文合同：正式上下文仍要求正式包；沙盘上下文只认本租户规则集。
4. 十条规则清单合同：每条都有来源、DSL、四类样本和安全动作。
5. 治理合同：全部规则能完成演练治理，但证据明确非生产签署。
6. 五个外圈场景服务测试。
7. 前端页面、免责声明、六态与整批运行测试。
8. 134 实机：15 个场景逐项运行，服务端回查租户、规则集、运行和审计事实。
9. 反向核验：`t-1` 规则、知识、Provider、医学评测和 P6 零变化。

## 9. 验收标准

- 15 个场景均返回真实 PASS，失败不得被跳过或降格为通过。
- 10 条规则全部由 `pilot-hospital` 自有，平台引用数为 0。
- 沙盘代码、脚本、页面、测试与当前接力文档不再包含旧固定版本号或配置包前置口径。
- 正式上下文、正式规则和正式资产门禁不被放宽。
- 所有场景证据含租户、规则集、来源、测试、治理、运行步骤、审计标识和演练免责声明。
- 134 上平台主源、Provider、医学评测运行与 P6 保持原状态。
