## 目标

将已确认的“平台知识主源 + 机构按需派生”和“自然人 + 任职 + 账号 + 身份来源”落成可运行、可审计、可批量维护、可由全角色前台验收的产品闭环。

## 任务 1：建立绿基线与契约测试

涉及：

- 知识身份、知识版本、继承覆盖测试
- 用户管理、身份绑定、登录测试
- 组织层级和前端路由测试

步骤：

1. 运行现有聚焦测试，记录绿基线。
2. 新增平台知识派生、本地覆盖发布、恢复平台标准失败测试。
3. 新增人员、任职、账号链接、批量导入幂等和冲突失败测试。
4. 新增中文枚举与组织树范围选择前端失败测试。

## 任务 2：知识定制血缘

新增：

- `mk_knowledge_customization`
- `KnowledgeCustomization` 领域对象、仓储、服务和控制器
- 平台基线、本地身份、本地版本、目标组织和生命周期字段

行为：

1. 从平台已发布权威版本创建本地草稿。
2. 同一平台身份和目标组织重复请求幂等返回现有草稿。
3. 本地版本发布后注册 `REPLACE` 覆盖。
4. 停用覆盖后恢复平台标准。
5. 查询返回平台更新状态和完整血缘。

## 任务 3：人员主数据与任职

新增：

- `mk_identity_person`
- `mk_identity_person_appointment`
- `mk_identity_person_account`
- 人员分页、详情、创建和任职维护接口

约束：

1. 工号租户内唯一。
2. 任职组织必须属于当前租户且状态有效。
3. 同一人员同一时间只有一个主任职。
4. 账号链接租户一致且一对一。
5. 离职保留历史并停用有效访问关系。

## 任务 4：批量入职任务

新增：

- `mk_identity_person_import_job`
- `mk_identity_person_import_row`
- CSV 模板、预检、提交、结果查询接口

步骤：

1. 上传 CSV 后解析标准字段。
2. 校验组织、科室、角色、账号和身份来源。
3. 按工号、登录名和身份摘要匹配。
4. 生成逐行处理建议和冲突。
5. 仅允许无阻断冲突的任务提交。
6. 事务内逐行处理并记录结果；任务级幂等。

## 任务 5：身份来源收口

1. 身份绑定改为关联人员和账号链接，不再把技术用户 ID 作为主要交互。
2. 增加批量绑定请求和逐行结果。
3. 停用人员时停用有效身份来源。
4. 页面展示人员、工号、任职和脱敏身份提示。

## 任务 6：组织和机构类型

1. 扩充医疗服务机构类型，覆盖综合医院、专科医院、独立分院、社区卫生服务中心、乡镇卫生院、村卫生室、门诊部和其它服务机构。
2. 保持稳定组织层级，不把机构类型误建成层级。
3. 提供组织树选择组件和中文层级词典。
4. 用户角色和知识范围全部改用组织节点选择。

## 任务 7：前端体验重构

页面：

- 登录
- 人员与账号
- 身份来源
- 知识治理
- 发布治理

要求：

1. 一页一目标，主按钮不超过一个。
2. 批量导入为人员管理主流程。
3. 范围编码和 JSON 编辑移入专家模式或彻底移除。
4. 六态完整，移动端无横向溢出。
5. 未接入统一身份时诚实降级。

## 任务 8：职责角色体系清理

1. 用职责角色替换早期固定岗位角色，集团、医院等层级只由组织范围表达。
2. 角色目录、默认权限、开发初始化账号、租户开通、MFA 策略和菜单矩阵全部切换到新编码。
3. 医师、护士、药师、医技、科主任等只作为任职专业或岗位，不再直接充当组织层级角色。
4. 直接改写全新数据库基线迁移，不增加旧角色删除或转换迁移。
5. 增加静态门禁，拒绝旧角色编码重新进入生产代码、初始化 SQL 和客户文案。

## 任务 9：客户可见中文枚举

1. 建立共享中文词典和安全回退函数。
2. 替换相关页面的裸英文枚举。
3. 增加静态测试，阻止已知客户枚举直接回显。
4. 保留行业缩写时补充中文解释。

## 任务 10：迁移与验证

1. 增加 H2、PostgreSQL、Oracle、达梦、人大金仓五方言迁移。
2. 校验中文 `COMMENT ON`、索引、唯一约束、组织/版本/审计字段。
3. 运行后端聚焦测试、全量测试和架构门禁。
4. 运行前端测试、类型检查、lint、stylelint、格式和构建。
5. 运行 T-GATE。

## 任务 11：全职责验收

1. 在本地真实页面准备脱敏演练数据。
2. 按设计中的十一类角色逐一执行主任务。
3. 保存关键页面和错误/空态证据。
4. 独立进行产品、医疗安全、安全合规、数据治理、架构、测试和运维评审。
5. 修复全部 P0/P1 以及影响主任务的 P2。
6. 更新 `_HANDOFF.md` 和验收报告，证据完整后结束目标。
