# 法律与合规材料边界

仓库不保存未签署的合同模板、客户专属条款或含个人信息的合规证据。正式上线前，由法务、商务和客户在受控文档系统完成并归档：

- 主合同与软件许可；
- 服务等级协议；
- 隐私政策与数据处理协议；
- 数据本地化、等保、密评和国产化适用性材料；
- 开源软件许可清单；
- 安全事件通知与应急责任。

工程侧只提供可核验事实：

- 产品安全红线见[产品宪法](../CONSTITUTION.md)；
- 数据、权限、审计和部署边界见[架构](../ARCHITECTURE.md)；
- 备份恢复步骤见[备份恢复 Runbook](../handbook/runbooks/backup-restore.md)；
- 上线验证见[质量基线](../audit/质量基线.md)。

任何法律承诺必须与真实部署能力一致，不得用仓库占位文本代替正式签署。
