# 共享体验与组件契约（EXPERIENCE_CONTRACT）

> 定位：客户可见页面和共用组件的体验契约；引擎与纯 API 能力只需遵守相关安全和状态约束。
> 全局硬约束（一页一目标、≤3 默认筛选、≤1 主按钮、AI 明显标识、菜单 IA 锁、设计变量）在 [核心 CONSTITUTION](CONSTITUTION.md) §产品体验 与 §设计变量；本契约**不重复核心原文**，只定可复用模式。

---

## 演练与体验重构准绳

全流程演练期间，所有客户可见页面按「找得到 / 看得懂 / 用得对」三项检查执行；体验优化 PR 必须能回答以下四问：

1. 外行 30 秒能否说出这页是干什么的？
2. 页内名词是否全部是医院语言，或能链接到词汇表？
3. 当前下一步动作是否明显，且不超过一个主动作？
4. 空、错、无权限、部分成功时，用户是否知道下一步怎么办？

四问每项 0–2 分；总分 ≤4 的页面必须登记体验优化项。体验优化项按「医疗安全 > 主链可用 > 高频页面 > 低频」排序，无需等待额外确认。

新增或改造客户可见页面还必须遵守五条演示重构原则：

| 原则 | 契约 |
|---|---|
| 医院语言 | 客户面默认说业务任务，不说内部引擎名；技术词必须能在 `docs/glossary.md` 找到客户面释义。 |
| 任务导向 | 导航、页头、主按钮围绕用户要完成的事，例如“配置危急值提醒”“查看推荐闭环”。 |
| 配置即可读 | 规则、路径、指标和机构生效版本等完成态必须提供自然语言回显；复杂配置同时提供只读图形/流程视图。 |
| 一图贯穿 | 跨页因果链必须有单页总览或可追溯入口，例如事件 → 规则 → 推荐 → 反馈 → 审计。 |
| 零迷路 | 每页显示当前位置、页面目的、下一步、出错找谁；空状态给第一步入口。 |

能力可见性审计以「后端能力是否有 UI 入口、并入既有页或明确 API-only」为闭环。无 UI 的能力不得被写成客户可操作功能；API-only 必须进入第三方对接案例集或接口文档。

## 导航与任务入口契约

| 入口类型 | 适用能力 | 固定规则 |
|---|---|---|
| 左侧主导航 | 稳定、高频、可由客户任务解释的业务页面 | 使用医疗引擎、知识生产、平台管理三个产品空间组织现有功能；按权限最小可见，不放阶段名和技术组件名 |
| 页头入口 | 跨域且高频的即时信息 | 只承载消息通知等即时入口；必须跳转到真实业务对象，不形成第二套导航 |
| 个人菜单 | 仅影响当前人员的设置 | 承载通知偏好、个人资料和安全设置；机构级策略仍回到对应治理页 |
| 高级能力 | 低频、高技术风险或仅供授权人员诊断的能力 | 与普通功能一样归入所属产品空间，由权限控制；不得形成独立工具主域，技术细节可在页内“高级信息”中渐进展示 |
| 页内步骤 | 与主页面共享对象和上下文的子任务 | 发布、试运行、结果、验收等使用页签、步骤或抽屉，不保留重复菜单 |
| 嵌入终端 | HIS/EMR 等院内工作站内的临床协同 | 通过受信启动进入，遵守最小数据和不阻断主流程 |
| 接口能力 | 仅供外部系统调用 | 不进入客户菜单，进入接口文档、联调单和健康检查 |

默认工作台必须根据四个可分配职责给出一个主动作和不超过三个高频入口；移动端侧栏收起后，三个产品空间顺序与桌面保持一致。面包屑必须使用客户业务名称，不显示旧域名、内部路由段或技术对象。

## 页面类型与固定结构

| 类型 | 用途 | 固定结构 |
|---|---|---|
| 工作台 | 看状态、风险、价值、待办 | 摘要卡 + 待办 + 风险 + 最近变化 |
| 列表页 | 找对象、筛选、批量、进详情 | 筛选 + 表格 + 服务端分页 + 详情抽屉 |
| 配置页 | 创建、校验、影响、发布和纳入机构生效版本 | 最小发布流 |
| 候选处理台 | 判断来源或模型候选是否可形成草稿 | 队列 + 左右对照 + 影响 + 责任结论 |
| 详情页 | 看一个对象全貌 | 摘要 + 状态 + 来源 + 版本 + 审计 |
| 嵌入面板 | 院内系统里给建议 | 小卡片 + 动作 + 解释抽屉 + 反馈 |
| 驾驶舱 | 看趋势和责任 | 指标 + 风险 + 下钻 + 行动 |
| 高级工具页 | 来源、知识关系、工作流、诊断 | 按普通功能归入产品空间，技术字段默认折叠并按权限展示 |

## 页面交互固定规则

| 项 | 固定规则 |
|---|---|
| 主按钮 | 每页最多 1 个；其它动作用次按钮/菜单/抽屉 |
| 默认筛选 | ≤3；更多进"高级筛选" |
| 表格列 | 默认 ≤8 列；技术字段/长文本/审计字段进详情 |
| 详情 | 长列表用右侧详情抽屉；打开详情不刷新列表 |
| 危险动作 | 删除/撤回/回滚/启用机构生效版本必须二次确认 + 展示影响范围 |
| 草稿保护 | 长表单/路径编辑/规则编辑自动保存草稿 |
| 可撤销 | 批量/发布/替换/同步提供回滚点或撤销解释 |

## 六态组件契约

每个页面必须齐全六态：**加载 / 空 / 错误 / 无权限 / 部分成功 / 正常**。

| 状态 | 契约 |
|---|---|
| 加载 | 骨架屏/进度反馈，内网慢场景必给 |
| 空 | 说明为什么空 + 下一步做什么 + 是否需要权限 |
| 错误 | 中文原因 + 重试入口 + traceId 复制按钮 |
| 无权限 | 不暴露敏感数据 + 说明权限范围 + 申请入口 |
| 部分成功 | 成功数 + 失败数 + 失败明细 + 可重试 |
| 正常 | 默认职责视图，技术对象折叠到“高级信息” |

## 大规模列表与性能门槛

| 场景 | 固定规则 |
|---|---|
| 普通列表 | 默认每页 20（可 50/100）；服务端分页；默认排序清晰 |
| 海量列表 | 游标分页；总数允许异步估算 |
| 审核队列 | 默认只看待我处理/高风险/新版差异；重复与旧版进已拦截视图 |
| 搜索 | 关键词/来源/知识身份/版本/组织/风险/状态/时间范围 |
| 保存视图 | 复杂筛选可存为个人视图 |
| 批量处理 | 选本页/选筛选结果/异步任务；**高风险不可批量自动通过** |
| 导出 | 大范围必须异步，记录筛选条件、操作者、时间、用途和结果；敏感导出由具备权限的操作者逐次确认 |
| 历史版本 | 默认当前版/上一版/待替换版；完整历史时间线分页 |

| 性能门槛 | 值 |
|---|---|
| 首屏加载 | P95 ≤ 1s（内网极端场景给骨架屏 + 进度） |
| 筛选响应 | P95 ≤ 2s |
| 详情打开 | 不触发列表重载 |
| 批量提交 | 立即返回任务 ID 与预计完成方式 |
| 导出 | 不阻塞页面；完成后通知并可追溯 |

## 临床嵌入与低打扰

| 项 | 固定规则 |
|---|---|
| 默认形态 | 在医生工作站/EMR/护理站嵌入轻量卡片或抽屉 |
| 打扰级别 | 信息提示不打断 / 重要风险弱打断 / **红线风险才强打断** |
| 动作 | 默认只有：采纳、不采纳并说明、稍后处理、查看依据 |
| 降级 | 引擎不可用时显示"智能建议暂不可用"，**不得阻断院内系统主流程** |
| 反馈 | 关闭/忽略/采纳/不采纳/稍后处理全部回传并审计 |
| 最小数据 | 嵌入启动只传当前场景必要字段 |
| 可读性 | 适配小屏、老旧浏览器、医生站低分辨率窗口 |

## 驾驶舱契约

| 规则 | 标准 |
|---|---|
| 指标有动作 | 每个指标必须能下钻到对象/责任人/科室/待办 |
| 不做装饰图 | 禁止只展示炫酷但不可行动的图表 |
| 先异常后全量 | 默认展示风险/异常/逾期/变化/趋势 |
| 价值指标 | 采纳率/误报率/漏报回溯/路径完成率/整改闭环率/医保违规减少 可配置 |
| 证据导出 | 管理视图能导出阶段报告或证据快照 |

## 表单/校验/发布契约

| 项 | 固定规则 |
|---|---|
| 表单分段 | >7 字段必须分组；>15 字段必须步骤化或折叠 |
| 默认值 | 能从组织范围、当前机构生效版本或历史配置推断的字段必须给默认值 |
| 实时校验 | 字段级错误就地提示；发布级错误进校验结果页 |
| 影响分析 | 发布/替换/撤回/回滚前必须显示影响组织/科室/患者/规则/路径 |
| 责任确认 | 高风险发布或临床确认必须填写理由；禁止用第二人、委员会或默认灰度替代当前责任 |
| 发布完成 | 展示资产版本、机构生效版本选择范围、同步状态、回滚点和证据入口 |

## 文案与视觉

| 项 | 固定规则 |
|---|---|
| 语言 | 客户可见默认中文；英文缩写仅保留 ICD/DRG/DIP/MPI/FHIR/OIDC 等行业标准 |
| 术语 | 按医疗引擎中枢语境保持专业准确，不机械通俗化；隐藏 B0、ACTIVE、MFA、token、tenant、payload 等实现代号，前台使用无模型规则链路、已生效、多因素认证、凭证、服务机构、请求内容等用户可理解表达 |
| 场景词 | 按用户任务命名：模型生产用生产前校验，候选进入审核用生产安全校验，发布用发布校验/发布质量校验，诊断用验证病例，机构开通用开通条件，路径时窗用时窗校验 |
| 语气 | 清楚、克制、专业；不营销化/夸张化/拟人化 |
| 按钮 | 动词 + 对象，如“校验草稿”“发布版本”“启用机构生效版本”“导出证据” |
| 风险文案 | 说明风险事实 + 影响范围 + 建议动作 |
| 颜色 | 只表达状态，不做装饰；危险色只用于真实危险（值见核心 §设计变量）|
| 字号 | 正文 14px；老年医生模式 ≥16pt |
| 可访问性 | 对比度、键盘可达、焦点态、表格可读性必须验收 |
| 主题 | 5 主题模式响应：default / elder / dark / eye / system |

## 与核心的边界

以下为**全局硬约束**，住在核心、不在本契约重复，页面卡通过"适用不变量"点编号引用：

- 一页一目标 / ≤1 主按钮 / ≤3 默认筛选 → 核心 §1 硬约束 #6（一页一目标）/ #16（体验门禁）
- AI 内容明显标识、医师确认、低打扰红线 → 核心 §临床医疗安全红线（#9/#10）
- 菜单 IA 锁（三产品空间 / 四职责 / 按权限最小可见 / `MenuPermissionCatalog` 目录权威）→ 核心 §菜单 IA 锁（#2/#3）
- 设计变量（色/字号/圆角/字体）→ 核心 §设计变量（#5）；本契约只引用变量名，禁硬编码
- 六态/分页/低打扰/可信解释/驾驶舱下钻 → 核心 §13 铁律 + 通用拒绝项

本契约只承载“页面类型 / 组件 / 交互 / 性能”的可复用模式；任何与核心冲突处以核心为准。
