# MedKernel 上线质量基线

## 1. 不可妥协项

1. 不伪造数据、模型调用、摘要、时延、连接或验收证据。
2. 无模型、图、缓存或外部系统时诚实降级，B0 主链仍可运行。
3. AI 内容明显标识；模型只产候选。
4. 医疗动作必须由医师确认，禁止自动开嘱、签署、支付、上报和设备控制。
5. 关系数据库是唯一业务事实源。
6. 同一适用域同时只有一个当前权威知识版本。
7. 四职责固定权限包、组织范围和机构数据隔离同时生效。
8. 页面具备加载、空、正常、错误、无权和降级六态。
9. 中文优先，追溯字段默认进入证据详情。
10. 业务配置外置并可审计。

## 2. 自动化验证

### 后端

```bash
cd medkernel-backend
mvn test
```

必须覆盖单元、服务、控制器安全、契约、集成、迁移和多方言 smoke。

### 前端

```bash
cd frontend
npm run verify
npm run build
```

必须覆盖 lint、stylelint、规则自测、格式、类型、组件测试和构建。

### 仓库门禁

```bash
node --test scripts/authenticity-guard.test.mjs
node scripts/authenticity-guard.mjs --mode=inventory
node --test scripts/config-boundary-guard.test.mjs
node scripts/config-boundary-guard.mjs --mode=inventory
node --test scripts/migration-convention-guard.test.mjs
node scripts/migration-convention-guard.mjs --mode=inventory
node --test scripts/performance-contract-guard.test.mjs
bash scripts/check-comment-zh.sh --self-test
bash scripts/check-comment-zh.sh --mode=full
git diff --check
```

## 3. 数据库验收

- 规范化模式模型可重复生成五份 V1 且无差异。
- H2、PostgreSQL、Oracle 空库真实执行。
- Kingbase、达梦静态方言合同通过；正式支持环境补真实运行证据。
- 所有表、字段、约束和索引完整；引擎与共享层中文注释完整。

## 4. 功能验收

- 按 [完整产品范围](../PRODUCT_SCOPE.md) 验证六层能力、S0–S40 和全医疗专业领域，不以当前页面库存代替产品验收。
- 44 条路由、54 个页面组件、34 个菜单全部保留并可达。
- 四个可分配职责的并集覆盖全部菜单和运行入口。
- 平台管理员完成 SaaS、账号、身份、接入、配置和运维。
- 医疗引擎运营员完成知识、规则、路径、质量、模型生产和发布。
- 临床使用者完成患者、路径、提醒、任务、随访和确认。
- 审计员以只读方式核查来源、运行和审计证据。
- MFA 默认关闭；开启后必须在登录时真实验证 TOTP。
- 大模型自动生成知识从来源到发布、运行、回滚形成真实闭环。
- 13 类标准患者资源、13 类版本化资产和 11 个知识内容分类均具备真实落点与运行消费者。
- 全医疗专业领域各有权威代表资产完成生产、发布、运行、降级和证据闭环。
- 五种交付形态、七类业务组合、完整医疗语义、专病十阶段和全中枢模型赋能矩阵均有自动化或
  目标环境证据。
- 平台、集团、医院、院区/成员机构、科室、病区、团队和专科/共享中心的组织与任职范围通过。
- 第三方系统族均有真实接入用例或明确 `NOT_CONNECTED` 降级，不允许用模拟成功代替。

## 5. 上线验收

必须在目标环境完成：

1. 备份和隔离恢复验证；
2. 清库并仅执行 V1；
3. 部署当前交付内容；
4. 四职责与内置超管登录；
5. 全部产品空间、菜单和关键业务旅程；
6. 权威来源、模型评测、候选生成、安全门、审核和发布；
7. 唯一权威读取、审计、重启、幂等、撤回和回滚；
8. 当前证据目录无凭据、患者明文或历史截图。
9. S0–S40、两家机构差异化机构生效版本、部分选择上线、平台升级和医院回滚可重放。
10. 仓库仅保留文档中心列出的当前文档，不存在旧卡、旧方案、阶段审计、历史截图或演练输出。
