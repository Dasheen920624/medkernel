# 接力文档 · 演练试点租户与全真沙盘（2026-06-19）

> 主接力以 [`docs/_HANDOFF.md`](../_HANDOFF.md) 为准；本文件只记录 `pilot-hospital`、沙盘规则、现场重放和 134 边界。

## 当前目标

在真实演练租户 `pilot-hospital` 建设纯粹、可审计、无外部副作用的全真沙盘：

1. 10 条演练定制规则全部作为演练机构真实资产创建；
2. CURRENT 仍支持平台主源规则，遵循“机构优先、平台补充、同编码机构覆盖平台”；
3. 场景不固定配置包版本，由机构运行绑定在启动时解析并冻结；
4. 支持现场历史原样重放和历史/当前新旧对比；
5. 推荐、路径、随访、评估和嵌入使用正式领域服务，不建设第二套演练引擎。

平台主源知识、规则和沙盘可建立只读运行关联，但演练机构不得修改平台资产。Provider、医学评测、专家签署链和 P6 仍属于生产放行边界，不能由沙盘自动化代签或绕过。

## 正确的运行与版本口径

- 场景模板只保存业务意图、触发点、期望规则编码和依赖资产，不保存配置包版本。
- CURRENT 从 `pilot-hospital` 唯一 ACTIVE 沙盘运行绑定解析可运行包，并在运行开始时冻结 package、资产版本、规则来源和内容摘要。
- 第三方上下文、事件和 CDS Hooks 仍可显式传版本；适配器也可使用受控默认绑定。请求与绑定均缺失时明确失败，不选“最新版本”。
- HISTORICAL_EXACT 只按不可变重放清单使用现场当时的上下文和资产版本，不读取当前 ACTIVE 规则。
- COMPARE 使用同一份脱敏上下文分别执行历史基线与当前基线，展示新增/取消命中、严重度、动作、来源、版本和 hash 差异。

## 十条机构演练规则

范围包括检验危急值、用药联用风险、检查与肾功能风险、诊断提示、报告危急结果、出院核查、随访异常、医保合规提示、病历内涵质控和病历结构完整性。

每条规则必须具备：

- 演练机构归属、稳定 `ruleCode`、结构化 DSL 和明确动作；
- 权威来源或已审核机构参数、适用范围、版本/发布日期和检索日期；
- 命中、未命中、边界、缺字段和冲突测试；
- 不自动诊断、不自动开嘱、不自动拒付的安全边界；
- 发布、包绑定、运行来源、审计和回滚证据。

缺少医学依据时，系统应把阈值设计为机构参数 schema 并返回准备度缺口，不得编造全国统一常量，也不得用静态目录状态永久搁置功能。

## 全流程验收

CURRENT、HISTORICAL_EXACT、COMPARE 均须覆盖：

1. 上下文快照与不可变运行基线；
2. 机构规则与平台规则的真实继承/覆盖来源；
3. 推荐卡；
4. 路径入径与推进；
5. 随访计划、任务、异常和闭环；
6. 质量发现、整改、复核和关闭；
7. IFRAME、SDK 和 API 嵌入合同；
8. 运行步骤、对象 ID、版本、摘要和失败原因审计；
9. Webhook、通知、短信、外发任务和现场写回全部被抑制。
